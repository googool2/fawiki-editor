# راهنمای بازبینی fawiki-editor

*English summary at the end.*

fawiki-editor ابزاری است که رسم‌الخط ویکی‌متن فارسی را خودکار اصلاح می‌کند و به Claude کمک می‌کند مقاله‌ای بنویسد که با شیوه‌نامهٔ ویکی‌پدیای فارسی بخواند. قواعد آن را Claude از روی شیوه‌نامه و کد ابزارهای خودِ ویکی‌فا (ربات زیباسازی، ابرابزار، اشتباه‌یاب) نوشته و روی مقاله‌های واقعی آزموده است. **هنوز هیچ ویراستار ویکی‌فا آن را بازبینی نکرده است.** این صفحه برای همین است.

## چه چیزی را بازبینی کنیم

۱. **۳۱ قاعدهٔ اصلاح خودکار (FA) و ۹ هشدار (FW).** فهرست کامل پایین همین صفحه است. سؤال اصلی برای هر قاعده: «آیا این اصلاح همیشه درست است، یا جایی هست که متن درست را خراب کند؟»
۲. **۲۹۷ اصلاح واقعی.** همهٔ اصلاح‌های غیرفاصله‌ای ابزار روی ۸۸ مقالهٔ واقعی ویکی‌فا، هر کدام با برچسب Claude («درست» یا «قابل‌بحث»). این‌ها در صفحهٔ بازبینی تعاملی هستند، چون متن مقاله‌ها در مخزن نگه داشته نمی‌شود.
۳. **قاعده‌های جاافتاده.** خطاهای رایجی که در پیش‌نویس‌ها می‌بینید و ابزار نمی‌گیرد.

لازم نیست همه را ببینید. ده رأی هم کمک می‌کند. مهم‌ترها: قواعد FA20 تا FA23 (نیم‌فاصله)، FA42 (فاصله بعد از نشانه‌ها)، FA50 (غلط‌های املایی) و همهٔ هشدارها.

## پرسش باز

`{{یادکرد کتاب}}` و `{{یادکرد ژورنال}}` در TemplateData پارامترهای `نویسنده`، `ترجمه` (کتاب)، `جلد` و `ناشر` (ژورنال) را ندارند، ولی ابزار یادکردساز ویکی‌فا (citer) آن‌ها را می‌نویسد. آیا این پارامترها در عمل کار می‌کنند؟ اگر می‌دانید، در فرم یا صفحهٔ بحث بنویسید.

## معنای رأی‌ها

| رأی | یعنی |
|---|---|
| درست | این اصلاح طبق شیوه‌نامه است و موردی نمی‌شناسم که متن درست را خراب کند. |
| قابل‌بحث | گاهی درست است و گاهی نه، یا ویراستاران بر سرش توافق ندارند. بهتر است فقط هشدار بدهد. |
| غلط | با شیوه‌نامهٔ ویکی‌فا نمی‌خواند یا متن درست را خراب می‌کند. |

برای هشدارها (FW)، «درست» یعنی گزارش‌دادنِ بدون اصلاح کار درستی است. «غلط» یعنی یا نباید گزارش شود یا باید خودکار اصلاح شود؛ در یادداشت بنویسید کدام.

## سه راه برای فرستادن نظر

۱. **فرم گیت‌هاب:** [بازبینی قواعد](https://github.com/googool2/fawiki-editor/issues/new?template=rule-review.yml). شناسه‌ها و رأی‌ها را خط‌به‌خط بنویسید.
۲. **صفحهٔ بازبینی تعاملی** (اگر پیوندش به شما داده شده): برای هر قاعده و هر اصلاح واقعی دکمهٔ رأی دارد و رأی هر نفر جدا ذخیره می‌شود. اگر ذخیره ممکن نبود، دکمهٔ «کپی رأی‌های من» متنی می‌دهد که می‌شود در فرم گیت‌هاب چسباند.
۳. **همان صفحهٔ بحث ویکی‌پدیا** که این درخواست در آن آمده است. نگه‌دارنده نظرها را به مخزن منتقل می‌کند.

## نتیجه‌ها چه می‌شوند

- قاعده‌ای که یک ویراستار با دلیل «غلط» بداند، در نسخهٔ بعد به هشدار تبدیل می‌شود تا بحث روشن شود. قاعده‌ای که چند ویراستار «غلط» بدانند حذف می‌شود.
- رأی «قابل‌بحث» با دلیل، اگر نمونهٔ مشخص داشته باشد، به آزمون تازه تبدیل می‌شود.
- همهٔ تغییرها در [CHANGELOG](../../CHANGELOG.md) با ذکر دلیل ثبت می‌شوند. اگر بخواهید، نام کاربری‌تان در یادداشت انتشار می‌آید.
- رأی‌ها به‌جای برچسب‌های Claude در `bench/label.py` می‌نشینند و دقت ابزار دوباره سنجیده می‌شود.

## فهرست قواعد

| شناسه | چه می‌کند |
|---|---|
| FA00 | حروف نمایشی عربی (مثل `ﺳﻼﻡ`) را به حروف معمولی برمی‌گرداند. |
| FA01 | `ي` و `ى` عربی ← «ی» فارسی. متن عربی، اویغوری، کردی، اردو و پشتو دست نمی‌خورد. |
| FA02 | `ك` عربی ← «ک» فارسی، با همان استثناها. |
| FA03 | رقم‌های عربی `٠` تا `٩` ← رقم‌های فارسی ۰ تا ۹. |
| FA04 | رقم لاتین در متن فارسی ← رقم فارسی. عبارت‌ها و کتاب‌شناسی‌های لاتین دست نمی‌خورند. |
| FA05 | کشیدهٔ `ـ` میان حروف را حذف می‌کند. |
| FA06 | `%` بعد از رقم فارسی ← «٪». |
| FA07 | نقطهٔ اعشار میان رقم‌های فارسی ← «٫» (نه در `۷۰۰.۰۰۰` یا شمارهٔ نسخه). |
| FA08 | ویرگول هزارگان میان رقم‌های فارسی ← «٬». |
| FA09 | نویسه‌های کنترلی و BOM را حذف می‌کند. |
| FA10 | نیم‌فاصلهٔ تکراری را یکی می‌کند. |
| FA11 | نیم‌فاصلهٔ چسبیده به فاصله را حذف می‌کند. |
| FA12 | نیم‌فاصلهٔ زائد بعد از حرف ناچسبان (ا، د، ر، و…) را حذف می‌کند. |
| FA13 | نیم‌فاصله‌ای را که میان دو حرف نیست حذف می‌کند (کنار پیوند می‌ماند). |
| FA14 | `ۀ`، `هء` و `ه ء` ← «هٔ». |
| FA15 | کسرهٔ اضافه به شکل `ه‌ی` ← «هٔ». |
| FA16 | `ه‌ئی` و `ه‌یی` ← «ه‌ای». |
| FA20 | «می»/«نمی» + ریشهٔ فعل شناخته‌شده ← با نیم‌فاصله (فهرست ریشه‌ها از ابرابزار). |
| FA21 | «ها»ی جمع بعد از فاصله ← با نیم‌فاصله (بعد از حرف ناچسبان، چسبیده). |
| FA22 | «ترین» بعد از فاصله ← با نیم‌فاصله. |
| FA23 | های غیرملفوظ + ای/ام/ایم/اید/اند ← با نیم‌فاصله («خانه‌ای»). |
| FA30 | ویرگول لاتین بعد از واژهٔ فارسی ← «،». |
| FA31 | نقطه‌ویرگول لاتین بعد از واژهٔ فارسی ← «؛». |
| FA32 | علامت سؤال لاتین بعد از واژهٔ فارسی ← «؟». |
| FA33 | گیومهٔ انگلیسی `“…”` دور متن فارسی ← «…». |
| FA40 | فاصلهٔ پیش از `. ، ؛ ؟ ! : ) »` را حذف می‌کند. |
| FA41 | فاصلهٔ بعد از `«` و `(` را حذف می‌کند. |
| FA42 | یک فاصله بعد از نشانه میان دو واژهٔ فارسی (نه در `ه.ق` یا `دی.آی.سی.ای`). |
| FA43 | چند فاصلهٔ پشت سر هم را یکی می‌کند. |
| FA44 | فاصلهٔ آخر خط را حذف می‌کند. |
| FA50 | غلط‌های املایی بی‌ابهام از فهرست اشتباه‌یاب (مثل `علیرغم` ← «علی‌رغم»). |
| FW01 | هشدار: `ي` یا `ك` عربی درون پیوند یا الگو (خودکار اصلاح نمی‌شود). |
| FW02 | هشدار: `تر` جدا («تر» ممکن است به معنای خیس باشد). |
| FW03 | هشدار: گیومهٔ صاف `"…"` دور متن فارسی. |
| FW04 | هشدار: تاریخ با / یا - در متن. |
| FW05 | هشدار: `ه ی` که شاید باید «هٔ» باشد. |
| FW06 | هشدار: عنوان‌های احترام (`حضرت`، `مرحوم`، `(ع)`…) طبق دیدگاه بی‌طرف. |
| FW07 | هشدار: `۱۹۸۰ها` ← «دههٔ ۱۹۸۰». |
| FW08 | هشدار: نام ماه‌های میلادی به شکل انگلیسی (`جولای`، `آگوست`…). |
| FW09 | هشدار: نقطه به‌جای جداکنندهٔ هزارگان (`۷۰۰.۰۰۰`). |

## English summary

fawiki-editor's 31 automatic fixes (FA) and 9 warnings (FW) were written and labeled by Claude; no
native fa.wiki editor has reviewed them yet. Reviewers vote درست (correct) / قابل‌بحث (debatable) /
غلط (wrong) per rule, and optionally per real-world fix, through the
[GitHub issue form](https://github.com/googool2/fawiki-editor/issues/new?template=rule-review.yml), the
interactive review page (if the maintainer shared it with you), or the wiki talk page where the call
was posted. A rule an editor calls wrong, with a reason, becomes a warning in the next release; votes
replace Claude's labels in `bench/label.py` and accuracy is re-measured.
