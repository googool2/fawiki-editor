# fawiki-editor

**یک مهارت (Agent Skill) برای Claude که کمک می‌کند مقاله‌های ویکی‌پدیای فارسی ([fa.wikipedia.org](https://fa.wikipedia.org)) را مطابق شیوه‌نامه و رویه‌های ویکی‌فا بنویسید، ترجمه کنید، بازبینی کنید و ویکی‌متن آن‌ها را لینت کنید.**

[English](README.md)

## مسئله

مدل‌های زبانی عمومی متنی برای ویکی‌پدیای فارسی می‌نویسند که در نگاه اول درست است، اما واگردانی یا حذف می‌شود: `ي` و `ك` عربی به‌جای «ی» و «ک» فارسی، نبودِ نیم‌فاصله، ارقام لاتین، الگوهای انگلیسی مثل `{{cite web}}` و `{{Reflist}}`، منبع ساختگی، لحن تبلیغاتی، موضوعی که سرشناس نیست و ترجمه بدون ذکر منبع. ویکی‌فا برای متن مدل زبانیِ بازبینی‌نشده معیار حذف سریع جداگانه‌ای (ع۱۵) دارد و شابک نادرست و پیوند مرده را از نشانه‌های آن می‌داند.

این مهارت **لایهٔ فارسی** است: قواعد خودِ ویکی‌فا (شیوه‌نامه، رسم‌الخط، عنوان‌ها، تاریخ‌ها، الگوهای یادکرد و جعبه اطلاعات فارسی، سرشناسی و حذف) را در فایل‌های مرجعی جمع می‌کند که Claude هنگام نیاز می‌خواند، و برای کارهای مکانیکی اسکریپت‌های قطعی دارد تا اصلاح رسم‌الخط به حافظهٔ مدل وابسته نباشد.

## محتوا

| مسیر | کار |
|---|---|
| `SKILL.md` | روند کار: تشخیص نوع کار، بررسی سرشناسی، قواعد منبع، اجرای اسکریپت‌ها، تحویل همراه با یادآوری دربارهٔ هوش مصنوعی |
| `references/` | هشت فایل مرجع: رسم‌الخط، عنوان‌ها، تاریخ و عدد، یادکرد، جعبه اطلاعات، ساختار مقاله، سرشناسی و حذف، ترجمه. هر قاعده به یک صفحهٔ ویکی‌فا یا کد ابزارهای ویکی‌فا ارجاع دارد، وگرنه برچسب `[UNVERIFIED]` می‌خورد |
| `scripts/fa_lint.py` | اصلاح رسم‌الخط فقط در متن: ی و ک، ارقام فارسی و `٬ ٫ ٪`، نیم‌فاصله برای «می»، «ها» و «ترین»، «هٔ»، نشانه‌های `، ؛ ؟ « »`، فاصله‌گذاری و فهرستی از غلط‌های املایی رایج. به داخل الگو، پیوند، `<ref>`، `<nowiki>`، نشانی وب، توضیح پنهان و ویژگی‌های جدول دست نمی‌زند. خروجی: گزارش و diff |
| `scripts/wikitext_check.py` | بررسی ساختار: براکت نامتوازن، `<ref>` بسته‌نشده، نبودِ `{{پانویس}}`، نبودِ رده، نبودِ عنوان پررنگ در سرآغاز، الگوی ناشناخته یا انگلیسی، عنوان بخش نااستاندارد و پیوند میان‌ویکی قدیمی |
| `scripts/cite_builder.py` | ساخت `{{یادکرد وب}}`، `{{یادکرد کتاب}}` و `{{یادکرد ژورنال}}` از نشانی وب، DOI یا شابک. تنها اسکریپتی که اجازهٔ دسترسی به شبکه دارد؛ با `--offline` فقط اسکلت می‌سازد و فیلدهای نامعلوم را خالی می‌گذارد |
| `scripts/infobox_builder.py` | ساخت ده جعبه اطلاعات رایج ویکی‌فا از دادهٔ سادهٔ YAML یا JSON |
| `examples/` | یک مقالهٔ درست، یک مقالهٔ معیوب با ده خطای عمدی و یک نمونهٔ قبل و بعد از ترجمه |
| `tests/` | آزمون‌های pytest، به‌ویژه برای اثبات این‌که لینتر داخل الگو، پیوند و ref را خراب نمی‌کند |
| `evals/` | ارزیابی تریگر و سناریوهای خروجی با معیار پذیرش |
| `docs/research-summary.md` | منشأ هر قاعده و فهرست مواردی که هنوز باید روی خودِ ویکی‌فا بررسی شوند |

## نصب

پیش‌نیاز: پایتون نسخهٔ ۳٫۱۰ یا بالاتر. اختیاری: `pip install mwparserfromhell` (تشخیص بهتر الگوها؛ بدون آن هم همه‌چیز کار می‌کند).

**Claude Code، به‌عنوان مهارت شخصی:**

```bash
git clone https://github.com/googool2/fawiki-editor ~/.claude/skills/fawiki-editor
```

**Claude Code، به‌عنوان افزونه (plugin):**

```text
/plugin marketplace add googool2/fawiki-editor
/plugin install fawiki-editor@fawiki-tools
```

فقط یکی از این دو روش را به کار ببرید تا مهارت دوبار بارگذاری نشود.

**claude.ai:** یک فایل زیپ بسازید که پوشهٔ بالایی آن `fawiki-editor/` باشد و آن را از بخش تنظیمات (Settings → Capabilities → Skills) بارگذاری کنید:

```bash
git archive --format=zip --prefix=fawiki-editor/ -o fawiki-editor.zip HEAD
```

**Codex CLI:** در پوشهٔ مهارت‌های کاربر (طبق مستندات Codex، `~/.agents/skills`) کلون کنید:

```bash
git clone https://github.com/googool2/fawiki-editor ~/.agents/skills/fawiki-editor
```

## کاربرد

کافی است به فارسی یا انگلیسی بخواهید:

- «یه مقاله ویکی‌پدیا فارسی درباره پل خواجو بنویس»
- «این مقاله رو طبق شیوه‌نامه ویکی‌فا چک کن»
- «این مقاله انگلیسی رو برای ویکی‌فا ترجمه کن»
- «یادکرد وب برای این لینک بساز»
- «چرا مقاله‌م حذف شد؟»

اسکریپت‌ها جداگانه هم کار می‌کنند:

```bash
python3 scripts/fa_lint.py draft.wikitext            # گزارش و diff؛ فایل دست‌نخورده می‌ماند
python3 scripts/fa_lint.py draft.wikitext --fix      # اعمال اصلاح‌ها
python3 scripts/wikitext_check.py draft.wikitext     # در صورت خطای ساختاری، کد خروج ۱
python3 scripts/cite_builder.py 978-964-8165-81-4 --offline
python3 scripts/infobox_builder.py --template film --skeleton
```

## نمونهٔ قبل و بعد

از فایل [`examples/translation-before-after.md`](examples/translation-before-after.md):

```wikitext
'''Lake Urmia''' is an [[endorheic lake|endorheic]] [[salt lake]] in [[Iran]].<ref>{{cite web |url=https://www.britannica.com/place/Lake-Urmia |title=Lake Urmia |website=Encyclopaedia Britannica |access-date=12 March 2024}}</ref>
== References ==
{{Reflist}}
[[Category:Lakes of Iran]]
```

به این تبدیل می‌شود:

```wikitext
'''دریاچهٔ ارومیه''' یک [[دریاچهٔ بسته|دریاچهٔ بستهٔ]] شور در [[ایران]] است.<ref>{{یادکرد وب
| عنوان = Lake Urmia
| نشانی = https://www.britannica.com/place/Lake-Urmia
| وبگاه = Encyclopaedia Britannica
| کد زبان = en
| تاریخ بازبینی = 2024-03-12
}}</ref>
== منابع ==
{{پانویس}}
[[رده:دریاچه‌های ایران]]
```

همراه با خلاصهٔ ویرایشی که از `[[:en:Lake Urmia]]` نام می‌برد و استفاده از هوش مصنوعی را اعلام می‌کند، الگوی `{{صفحه ترجمه‌شده|en|Lake Urmia}}` برای صفحهٔ بحث، و فهرست پیوندهایی که کاربر باید وجودشان را بررسی کند.

## محدودیت‌ها

- **در زمان تحقیق دسترسی مستقیم به ویکی‌فا نبود.** محیط ساخت به wikipedia.org راه نداشت؛ قواعد از بریده‌های موتور جستجو از صفحه‌های ویکی‌فا و از کد منبع ابزارهای خودِ ویکی‌فا گرفته شده‌اند (ربات زیباسازی، نسخهٔ پایتونی ابرابزار و فهرست‌های اشتباه‌یاب در مخزن PersianWikipedia/fawikibot، و ابزار یادکرد citer). هر مورد با برچسب `[LOW]` یا `[UNVERIFIED]` را روی صفحهٔ زنده بررسی کنید؛ فهرست کامل در `docs/research-summary.md` است.
- نام پارامترهای جعبه‌های اطلاعات بیشتر با اطمینان کم `[LOW]` ثبت شده‌اند؛ آن‌ها را با صفحهٔ توضیحات الگو تطبیق دهید.
- لینتر عمداً محافظه‌کار است: به برچسب پیوندها و پارامترهای الگو دست نمی‌زند و در موارد مبهم («تر»، «ه ی»، گیومهٔ لاتین، القاب) فقط هشدار می‌دهد.
- اسکریپت‌ها نمی‌توانند وجود صفحه، رده یا الگو را در ویکی‌فا بررسی کنند.
- این مهارت هرگز ویکی‌پدیا را مستقیم ویرایش نمی‌کند. انتشار با شماست و مسئولیت متن هم با شما.

## نسبت با Wikipedia-AI-Skills

مجموعهٔ [fuzheado/Wikipedia-AI-Skills](https://github.com/fuzheado/Wikipedia-AI-Skills) ابزارهای عمومی ویکی‌مدیا را پوشش می‌دهد: تجزیهٔ درخت نحوی ویکی‌متن، یادکردهای CS1، ارزیابی کیفیت، OAuth و واسط‌های برنامه‌نویسی. fawiki-editor این‌ها را تکرار نمی‌کند؛ فقط آنچه مخصوص ویکی‌پدیای فارسی است را می‌افزاید، به‌تنهایی کار می‌کند، و اگر آن مجموعه نصب باشد، برای کار در سطح درخت نحوی به مهارت `wikimedia-wikitext` ارجاع می‌دهد.

## توسعه

```bash
pip install pytest mwparserfromhell
python3 -m pytest -q
python3 scripts/fa_lint.py README.fa.md --check   # همین فایل هم باید بدون خطا از لینتر رد شود
```
